阅读完整安装与修复说明 ↗
  1. 1

    下载并安装连接器

    下载 Apple Silicon DMG，打开 BeeHelper Installer，选择“安装 / 修复”。预览包尚未完成 Developer ID 签名和 Apple 公证，系统可能阻止启动。

  2. 2

    在 Chrome 加载扩展

    在 chrome://extensions/ 开启开发者模式，选择“加载已解压的扩展”，载入安装器打开的 extension 文件夹。在扩展详情启用“允许用户脚本”。

  3. 3

    打开侧边栏，试试第一个微应用

    点击 BeeHelper 图标，跟随首次使用向导，从示例画廊试用“批量文本整理”。连接 AI 需另行安装并登录本地 Agent；Claude Code 还需要 ACP 适配器。
