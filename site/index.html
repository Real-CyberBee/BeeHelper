阅读完整安装与修复说明 ↗
  1. 1

    下载并安装连接器

    按系统选择安装包。macOS 运行 DMG 中的安装器，Windows 完整解压后运行 install.cmd，Linux 解压后运行 ./install.sh。均使用当前用户安装。

  2. 2

    在 Chrome 加载扩展

    在 chrome://extensions/ 开启开发者模式，选择“加载已解压的扩展”，载入安装器打开的 extension 文件夹。在扩展详情启用“允许用户脚本”。

  3. 3

    打开侧边栏，试试第一个微应用

    点击 BeeHelper 图标，跟随首次使用向导，从示例画廊试用“批量文本整理”。连接 AI 需另行安装并登录本地 Agent；Claude Code 还需要 ACP 适配器。

A FEW THINGS TO KNOW

开始之前，你可能想知道。

一定要连接 AI 才能使用吗？

不需要。已有的微应用可以独立运行；只有希望 AI 创建或修改工具时，才需要连接本地 Agent。

需要另外安装 Node.js 吗？

发布包不需要。macOS 使用系统运行时；Linux 和 Windows 包内包含 Node。源码开发和第三方 Agent 可能有自己的运行时要求。

安装包会替我安装并登录 AI 客户端吗？

不会。请独立安装、登录 Codex、Claude Code 或 DeepSeek Harness。Claude Code 还需 ACP 适配器，账号权限和模型额度由客户端提供。

可以直接在 Chrome 应用商店安装吗？

当前尚未上架商店。请使用开发者模式，加载安装器输出的 extension 目录，并启用“允许用户脚本”。

微应用会自动运行或提交操作吗？

导入的用户脚本先成为候选，默认手动运行。安装后行为取决于具体源码、触发方式与权限；运行前应检查内容。停止或卸载不会撤销已经发生的网页操作。
