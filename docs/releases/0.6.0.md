# BeeHelper v0.6.0 · 跨平台公开预览版

浏览器侧边栏里的 AI 微应用工作台。这个版本新增 Windows / Linux 下载，补齐 macOS Intel 构建，并推出站内文档中心。

## 下载内容

- **macOS Apple Silicon / Intel**：DMG，使用 Swift 与系统 JavaScriptCore，包含扩展和连接器，不捆绑 Node。
- **Windows x64**：ZIP，完整解压后运行 `install.cmd`。包内含 Node、exe Native Messaging 宿主与扩展，当前用户安装，无需管理员。
- **Linux x64**：tar.gz，解压后执行 `./install.sh`，无需 sudo。包内包含 Node 与扩展，要求 glibc 2.28+。
- **SHA256SUMS.txt**：四个分发文件的校验值。

[官网下载区](https://real-cyberbee.github.io/BeeHelper/#downloads) · [分平台安装指南](https://real-cyberbee.github.io/BeeHelper/docs/install.html) · [文档中心](https://real-cyberbee.github.io/BeeHelper/docs/)

## 本次新增

- Windows 命名管道通信、真正的 exe 宿主、二进制标准流转发和标准 npm JavaScript shim 识别。
- Linux / Windows 使用每用户的版本目录，支持安装、修复、失败时保留已有安装与卸载宿主登记；保留旧扩展目录和用户数据。
- 官网新增四种架构下载、三个微应用示例、FAQ 和站内文档。Markdown 文档自动生成 HTML，提供侧栏、标题锚点和窄屏折叠导航。
- 既有微应用、Agent 会话、脚本市场与 13 个示例继续沿用现有实现。

## 预览范围

需要 Chrome 138+，在开发者模式加载安装器输出的 `extension` 目录，并启用“允许用户脚本”。扩展尚未上架商店。

macOS 编译目标为 13+；Windows 面向 Windows 10 / 11 x64，需要 .NET Framework 4.x；Linux 面向 x64、glibc 2.28+。Linux / Windows ARM、musl 发行版和沙箱浏览器暂未提供验收。

macOS 安装包只有临时签名，尚无 Developer ID 签名和 Apple 公证；Windows 启动器尚无 Authenticode 签名，系统可能阻止启动。CI 的隔离安装与协议夹具不能替代所有系统版本的干净机器 GUI 验收。

已有微应用无需连接 AI。AI 创作仍需独立安装并登录 Codex、Claude Code 或 DeepSeek Harness；Claude Code 还需要 ACP 适配器。安装包不包含模型账号、额度或第三方 Agent 登录，不自动桥接 Windows 与 WSL。
