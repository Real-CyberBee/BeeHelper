# 示例画廊

入口：侧边栏左侧「示例画廊」，或微应用库顶部的 WOW 卡片。共 13 个示例，全部是可直接运行的微应用源码，不依赖额外的工程或构建。

每个示例都可以：

- **添加**：进入候选库，可改源码、让 AI 接着改；
- **添加并试试**：直接运行一次（界面型在侧边栏预览，页面型在目标网页运行）；
- 选中示例后对 AI 说“在这个基础上加……”，它会读取源码继续修改；
- 全部添加到候选库后，可批量改造成自己的工作台。

## 设计这些示例时的取舍

- **不依赖外部账号或接口**：每个示例在普通网页或本地测试页就能演示，避免“看起来厉害但跑不起来”。
- **默认不提交不可逆操作**：跨页表单流水线只填写、不提交，把是否提交留给用户。
- **明确能力边界**：每个示例都写了一句“能力边界”说明，让人看懂它为什么能成立，而不是只看到一个成品。
- **源码尽量短**：单文件、无构建、只用公开 SDK，方便直接改。示例本身就是教学材料。

## 想加自己的示例？

示例定义在 `src/core/demos.ts`，结构是：

```ts
{
  id: "my-demo",
  emoji: "🧪",
  title: "我的示例",
  tagline: "一句话说清它做什么",
  highlight: "它展示了什么能力边界",
  tags: ["标签"],
  definition: { schemaVersion: 1, title, description, kind: "panel" | "page", matches: ["..."], trigger: "manual", code: "..." }
}
```

`npm test` 会校验每个示例的定义合法、`id` 唯一、源码可以编译；新增示例不用改测试。格式说明见[微应用 SDK](microapp-sdk.md)。
